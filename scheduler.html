Separate photo posts · multiple Pages

Bulk Pages

Choose 1–10 separate photos. Every photo can target a different set of Pages, with its own caption and schedule. A single photo can still be published immediately.

▦
Choose the number of separate photos first. With one photo, Publish Now is available. With two or more photos, the batch must use Schedule.
Each photo becomes its own post. This is different from adding multiple photos to one album post.
Choose any interval from 1 to 60 minutes.
Use Apply interval to set the next photo times automatically.

For 2–10 photos, publishing immediately is disabled intentionally: the photos are scheduled as separate posts. Page access, future-time checks, and Facebook limits still apply.

Separate posts · one Page

Bulk Photos

Choose one Page, then create 1–10 separate post slots. Every slot has its own caption and can contain 1–10 images.

▧
This composer is separate from Bulk Pages: each slot is its own post. Publishing stays disabled until the dedicated Phase 3 API is ready.
Schedule each post
Bulk Photos only creates scheduled posts. Set a future date and time for every post slot.
